Add `@inflate-ai/imaxt-editor`, a Medium-style Markdown/MDX editor built on Lexical: full standard Markdown editing (headings, lists, tables, checklists, quotes, code, links, images) with every Imaxt block reachable from the same `/` insert menu on the same document, a configurable theme (reading the same CSS tokens `imaxt-core`/Blog already use), and a pluggable `ImageStorageAdapter` for image uploads (defaults to in-memory, no backend required).
