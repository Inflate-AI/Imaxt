# Security Policy

## Supported versions

This project is pre-1.0 (`0.x`). Security fixes target the latest
published version of each package; there is no long-term support branch
yet.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for a security
vulnerability. Instead, use GitHub's private vulnerability reporting for
this repository (the "Security" tab → "Report a vulnerability"), or open
a draft security advisory if that option isn't available to you.

Include:

- The affected package(s) and version(s).
- A description of the vulnerability and its impact.
- Steps to reproduce, or a minimal example.

We'll acknowledge reports within a reasonable timeframe and keep you
updated as a fix is developed. Once a fix is published, we'll credit the
report (unless you'd prefer otherwise) in the release notes.

## Scope

This covers the four packages published from this repository
(`@inflate-ai/imaxt-core`, `@inflate-ai/imaxt-editorjs`,
`@inflate-ai/imaxt-mdx`, `@inflate-ai/imaxt-astro`). A vulnerability in a
dependency should generally be reported upstream as well; if it
specifically affects how these packages use that dependency, report it
here too.
